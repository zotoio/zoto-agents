Equation Art

Images as invented math. The agent writes eqart-ir/2 programs: sandboxed, multi-pass JSON built from closed forms, soft masks, SDFs, per-pixel iteration, cellular automata and PDE simulations. A local MCP server validates, renders and measures them. Programs are interpreted and never executed as Python, and by default no pretrained weights are used anywhere.

Plugin version 0.2.0. Requires uv on PATH.

Fractals

Four families: IFS, L-systems, spirals and escape-time sets. A Barnsley fern is a 9 KB generative SVG that flattens to about 4 MB. IFS maps descend levels in proportion to how much they shrink. Spirals use binary doubling. Depth is capped at 60k instances so resvg can render the result. Mandelbrot and Julia sets come out as contour SVGs. Every SVG the plugin writes embeds its spec and round-trips exactly. Foreign SVGs are rasterized with resvg and fitted: IFS by a density-based collage fit, Julia sets by a c search, and L-systems against a template library.

WebGPU / WebGL2 3D

eqart_export with targets: ["webgpu"] transpiles a program to WGSL and GLSL. It writes a self-contained viewer.html that tries WebGPU first and falls back to WebGL2. The viewer has a 2D view and a 3D view that raymarches a height field (luminance, or the program's SDF). Field programs such as Gray-Scott are shown as a texture.

Judging iterations

eqart_judge recommends accept / revise / reject for each improvement round. It uses Jev (TypeSafe System One, image assets + Box) when TYPESAFE_API_KEY is set. Without a key it uses weight-free PSNR / MS-SSIM when there is a target image, and otherwise the host agent's own visual critique. The key is never logged, and judges never apply changes.

Optional extras

  • svg: resvg-py for SVG cross-checks and foreign-SVG fitting.
  • gpu-preview: wgpu for a native WGSL preview.
  • weights: opt-in perceptual (LPIPS) judge. Never required, and no weights are downloaded at install time.
