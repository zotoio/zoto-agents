# z-crux-skill-memory-meditation-research

Shortcut for the `crux-skill-memory-meditation-research` skill in this plugin.

The `crux-cursor-meditation-guide` agent normally loads this skill during `/crux-meditate`. Run it directly to inspect or reuse one step of a meditation.

## Usage

```
/z-crux-skill-memory-meditation-research outline phases A to G
/z-crux-skill-memory-meditation-research what does the depth-0 manager do in step 8
```

## Instructions

Load and follow the `crux-skill-memory-meditation-research` skill (`skills/crux-skill-memory-meditation-research/SKILL.md` in this plugin). Treat any text after the command as the user's request to that skill; with no text, start the skill from its first step. Follow the skill's steps and safety rules as written, and do not add behaviour the skill does not describe.
