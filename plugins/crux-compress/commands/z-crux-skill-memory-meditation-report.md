# z-crux-skill-memory-meditation-report

Shortcut for the `crux-skill-memory-meditation-report` skill in this plugin.

The `crux-cursor-meditation-guide` agent normally loads this skill during `/crux-meditate`. Run it directly to inspect or reuse one step of a meditation.

## Usage

```
/z-crux-skill-memory-meditation-report build the report for the latest meditation
/z-crux-skill-memory-meditation-report what must the report contain
```

## Instructions

Load and follow the `crux-skill-memory-meditation-report` skill (`skills/crux-skill-memory-meditation-report/SKILL.md` in this plugin). Treat any text after the command as the user's request to that skill; with no text, start the skill from its first step. Follow the skill's steps and safety rules as written, and do not add behaviour the skill does not describe.
