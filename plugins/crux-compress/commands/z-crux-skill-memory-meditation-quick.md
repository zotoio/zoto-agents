# z-crux-skill-memory-meditation-quick

Shortcut for the `crux-skill-memory-meditation-quick` skill in this plugin.

The `crux-cursor-meditation-guide` agent normally loads this skill during `/crux-meditate`. Run it directly to inspect or reuse one step of a meditation.

## Usage

```
/z-crux-skill-memory-meditation-quick how does quick mode differ from research mode
/z-crux-skill-memory-meditation-quick list the six steps
```

## Instructions

Load and follow the `crux-skill-memory-meditation-quick` skill (`skills/crux-skill-memory-meditation-quick/SKILL.md` in this plugin). Treat any text after the command as the user's request to that skill; with no text, start the skill from its first step. Follow the skill's steps and safety rules as written, and do not add behaviour the skill does not describe.
