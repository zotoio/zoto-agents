# z-eqart-compose

Shortcut for the `eqart-compose` skill in this plugin.

## Usage

```
/z-eqart-compose a spiral galaxy in teal and gold
/z-eqart-compose autumn trees on a pink ground
```

## Instructions

Load and follow the `eqart-compose` skill (`skills/eqart-compose/SKILL.md` in this plugin). Treat any text after the command as the user's request to that skill; with no text, ask what they want. Follow the skill's setup and safety steps as written, and do not add behaviour the skill does not describe.
